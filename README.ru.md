# HeadsetControl Taskbar Battery Indicator (Индикатор заряда наушников)

Легковесное приложение для Windows, которое отображает индикатор заряда батареи для различных беспроводных игровых наушников на панели задач или в виде оверлея.

## Возможности
- **Индикатор заряда:** Отслеживает уровень заряда вашей беспроводной гарнитуры прямо на панели задач.
- **Поддержка множества устройств:** Работает с широким спектром гарнитур, включая Logitech, SteelSeries, Corsair, HyperX и другие.
- **Настройки:** Возможность скрыть индикатор при отключении устройства и выбрать стиль отображения.

## Принцип работы
Приложение запрашивает уровень заряда батареи вашей гарнитуры, используя встроенный инструмент `headsetcontrol`, и бесшовно отображает статус в интерфейсе Windows.

## Благодарности и используемые репозитории
В этом проекте используются или берутся за основу следующие open-source проекты:

- **[HeadsetControl](https://github.com/Sapd/HeadsetControl)** - Базовый инструмент для получения статуса батареи различных наушников.
- **[headset-battery-indicator](https://github.com/aarol/headset-battery-indicator)** - Референс логики для работы с батареей.
- **[HeadsetControl-SystemTray](https://github.com/zampierilucas/HeadsetControl-SystemTray)** - Референс интеграции в системный трей (область уведомлений).
- **[TrafficMonitor](https://github.com/zhongyang219/TrafficMonitor)** - Референс техник рендеринга оверлея и пользовательского интерфейса.
